# Menendez Realty Group Website

Deploy-ready React + Vite project.

## Local setup

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Vercel

1. Upload this full folder to GitHub.
2. Connect the GitHub repo to Vercel.
3. Leave build settings as default:
   - Framework: Vite
   - Build command: npm run build
   - Output directory: dist
4. Deploy.
