# Menendez Realty Group Website

Deploy-ready React + Vite website with real routed pages for Figma import.

## Real page URLs
- /
- /about
- /buyers
- /sellers
- /listings
- /testimonials
- /contact

## Deploy to Vercel
1. Upload all files/folders in this project to GitHub.
2. Connect the GitHub repo to Vercel.
3. Keep defaults:
   - Framework: Vite
   - Build command: npm run build
   - Output directory: dist
4. Deploy.

Then import each live URL into Figma using html.to.design.
